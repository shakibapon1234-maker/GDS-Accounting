⚙ Supabase Settings

আপনার Supabase প্রজেক্টের URL ও anon key দিন। একবার দিলে সব PC-তে (localStorage-এ) সেভ থাকবে।

প্রথমবার সেটআপ (৫ মিনিট):
১. supabase.com-এ ফ্রি অ্যাকাউন্ট খুলুন → New project তৈরি করুন
২. SQL Editor-এ গিয়ে schema.sql ফাইলের কোড paste করে Run করুন
৩. Settings → API থেকে Project URL ও anon public key কপি করুন
৪. এখানে paste করে Save করুন — PC থেকেও GitHub থেকে এই ফাইল চালু করে same settings দিলেই ডেটা সিঙ্ক হবে
